====================================

  nvim --headless --startuptime /tmp/wb21-startup-final-20260913b.log -c 'qa!'

Neovim reached the NVIM STARTED marker at 62.613 ms, below the 150 ms host
budget. The profile sourced plugin/workbench.lua but did not load
workbench.services.operations, workbench.controllers.files, or
workbench.providers.lsp. Filesystem operations remain lazy until a Files
controller is created.

  host first input state: p50 2.148 ms, p95 2.408 ms

The WB-21 real RPC operation journey measured 14.900–38.665 ms from the Files
key through exact review, explicit confirmation, and destination creation over
both supported Neovim versions and four UI grids. Full benchmark samples and
RPC result/grid artifacts are retained under .bench-output/startup/ and
.test-output/e2e/wb21/.
