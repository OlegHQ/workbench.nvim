## Findings

- Fixed WB-19 override disposal removing sibling settings for the same owner. The new regression failed before the fix and passes across workspace/session/buffer scopes on both runtimes.
- Fixed WB-05 reentrant scope disposal: a disposer calling its own scope's disposal no longer reads an uninitialized report or aborts its cleanup. The regression failed before the fix.
- Fixed WB-10 ignoring explicit scope/query changes when Search was already open, overriding a new scope with retained history on reopen, and failing to refocus an existing view. Workspace changes close the previous view and invalidate owned requests before opening the new one. Tests cover explicit empty and invalid queries too.
- Fixed WB-10 search file labels showing long absolute paths that hide filenames on small grids. Workspace-relative labels retain raw URI/path identity and escape display text once.
- Fixed WB-06/18 scrolled tree projections losing their visible parent context. The previous-items indicator now retains the parent label when the first visible item is a child. This resolved the working-set journey's hidden file label.
- Fixed WB-18's existing E2E driver being omitted from `make test-e2e`; both Neovim versions and all four grids are now included.
- Fixed runtime preview enablement and output-byte limits, plus live sidebar width/position. The composition root injects one settings application callback. Source configuration, snapshot restore and override registration/disposal apply the actual runtime and roll back on failure; recursive mutation is rejected. Tests verify real windows, repeated preview toggles, session/workspace overrides, resource stability and injected failure recovery. Geometry now accepts the schema's full 16..80 width range while preserving compact overlays and editor focus.
- Fixed public runtime root retention and per-tab isolation. View changes reuse the selected tab snapshot despite cwd changes. An explicit root change invalidates Search and updates Files; closing a tab releases unshared workspace/cache state. A new owned TabClosed hook is scope-guarded and disposed on disable. Invalid query options are rejected before they can replace an existing workspace.
- Fixed contextual search debounce and result caps remaining frozen at construction. Queries capture per-request/per-result caps without mutating shared service ceilings. Live cap changes cancel and rerun the affected query; debounce changes replace only pending timers. Reopening a view reconciles its retained result cap. Aggregate disk/buffer overflow now stops owned lanes with visible truncation instead of attempting more merges into a terminal set. Regressions cover sibling tabs, retained results, override disposal, invalid caps, dirty buffers and disposal with a pending timer.

## Resolved Follow-Ups

Follow-active-file follow-up: Files now owns a listener only while mounted and enabled, deduplicates real editor paths, preserves focus/root, and removes the listener on disable/close/disposal. Reveal continuations check captured view identity, workspace generation and reveal generation. A delayed continuation invoked after close is rejected. Alias follow-up now preserves lexical in-root paths and resolves outside-looking aliases once, accepting them only when their canonical target remains inside the selected root. Enabling follow prefers the current real editor window instead of a stale original window; a second-split regression verifies this.

Visibility-policy follow-up: effective hidden/ignored/symlink settings now refresh retained tab snapshots, Files and Search; workspace overrides dispose back to configured values. UI toggles synchronize sibling views/tabs and retain only changed policy fields. Include/exclude controls no longer fail at the runtime bridge. Search capability caching no longer accumulates every workspace generation. Symlink traversal remains explicitly unsupported by Search's existing containment contract and returns to ready when disabled.

Session-settings follow-up: history limits now apply to live and closed investigations, preserve the current historical entry and release discarded session handles. The 16-entry setting can advance past 16 queries by releasing an old owned reference before allocation. Public persistence now rejects saves with `session.persist=false` before service construction, while retaining explicit read/delete operations. Enabling persistence never automatically saves or runs restored state. Public save callers in the recovery harness now opt in; direct service callers are unchanged.

Sidebar switching, contextual view gating, configured-order cycling and the runtime-owned Problems action route are tested. Problems is discoverable through Search's palette before loading its controller/provider. Disabled-view rejection, constructor failure and mount failure preserve workspace state. Search, Files, Outline and Problems stage replacement views/sessions and commit a new root only after successful open. Files and Problems have real-provider runtime and manual-input retention evidence. Actual Pyright transport covers Outline selection/expansion/order retention, while WB-13 independently covers manual input and rendering with injected callbacks. Outline's retained state has a 16-record bound.
